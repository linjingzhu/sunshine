entry is about *this* codebase. A lesson carried across repositories becomes
advice, and advice is what `LESSONS_FROM_PRACTICE.md` is for.

## Recording rule

Add only concise, evidence-backed facts such as:

```text
### 2026-XX-XX — <lesson>
Area:
Evidence:
Impact:
Recommended future behavior:
Confidence:
```

Prefer facts that can change future task decomposition, verification timing, or
conflict prevention.

**Evidence is the field that decides whether the entry is worth keeping.** A
lesson whose evidence line is a feeling is a feeling. Write the file path, the
build number, the measured value, the exact error.

Remove or replace stale lessons when repository reality changes. An append-only
file that nobody prunes stops being read.
